Learning System

This self-learning system connects the sign-in/out project to Python, data, API thinking, and AI product design. Students learn one concept, practice it on a small example, then convert it into a visible project deliverable.

1. Learn the Operation

Start from a real school workflow: student search, classroom lookup, sign in, sign out, attendance export, and staff review.

2. Turn Actions into Data

Convert each action into fields such as student_id, date, room, sign_in_time, sign_out_time, status, and notes.

3. Practice Python Thinking

Use strings, dictionaries, CSV files, functions, pandas, and charts to analyze the demo attendance records.

4. Understand API Logic

Read mock JSON responses to understand endpoint, request, response, status code, and error handling before touching any real system.

5. Add AI Support

Use teacher comments and structured prompts to generate parent-friendly summaries, next steps, and support suggestions.

6. Build the Demo Product

Combine data analysis, AI summary, student profile, dashboard, and responsible AI notes into a final team presentation.
